下载与运行示例

每节课的主示例都是完整的 Java 程序，可以在自己的电脑上运行、修改参数、对照课程中的输出。

下载 Java 示例

开始运行

  1. 安装 JDK 21 或更高版本，确认 java -version 与 javac -version 可用。
  2. 解压下载文件，进入 java-depth 目录。
  3. 运行与课程编号对应的示例，课程名之后可以追加 JVM 参数。
cd java-depth
./run.sh l01
./run.sh l05 -XX:-DoEscapeAnalysis

不用脚本时，先编译再运行：

javac -encoding UTF-8 -d out src/L01.java
java -cp out L01

第 04 节需要 JOL

第 04 节用 openjdk/jol 读取对象布局。运行前先把 jol-core 下载到 lib 目录：

mkdir -p lib
curl -fLo lib/jol-core-0.17.jar https://repo1.maven.org/maven2/org/openjdk/jol/jol-core/0.17/jol-core-0.17.jar
./run.sh l04

常见问题

现象处理
Windows 上不能执行 run.sh用上面的 javac / java 两条命令；classpath 分隔符写成 ;，例如 java -cp "out;lib/jol-core-0.17.jar" L04。
中文输出是乱码Windows 先执行 chcp 65001，或给 java 加上 -Dstdout.encoding=UTF-8。
输出与课程不同线程名单、GC 名称、对象布局都会随 JDK 版本和机器条件变化。课程输出以 JDK 21.0.11、x86_64 Linux 实测；先比较结构和数量级，再查对应 JDK 的文档。
