# Impeccable skill

`impeccable/` is copied from [pbakaus/impeccable](https://github.com/pbakaus/impeccable) at commit e103efe (skill version 4.5.0, engine 0.1.11), Apache-2.0 (see `impeccable/LICENSE` and `impeccable/NOTICE.md`). It is the project-level copy of the `.claude/skills/impeccable` folder from that repository, so every Claude Code session here can run `/impeccable` for frontend design work.

The launcher `impeccable/scripts/impeccable` downloads its engine binary to `~/.impeccable/bin/` on first use. No design hook is installed; run `impeccable detect` manually after UI edits. To update, copy the folder again from a newer commit.
