# Matt Pocock skills

These skill folders are copied from https://github.com/mattpocock/skills
(commit d81f3a1, plugin version 1.2.3, MIT license, see MATTPOCOCK-LICENSE).
Only the skills listed in the upstream `.claude-plugin/plugin.json` are included;
`misc/` and `in-progress/` are left out.

Common entry points: `/grill-with-docs` (grill requirements against the repo's docs),
`/grill-me` (grill without docs), `/ask-matt` (which skill fits).

To update: clone the upstream repo and re-copy each folder listed in
`.claude-plugin/plugin.json` into `.claude/skills/`.
