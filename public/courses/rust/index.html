如何使用这份教程与运行示例

每节包含规则、完整代码、输出解析、即时判断题和主动回忆题。先做题再展开答案；如果判断正确但说不出原因，继续练习。

本课程覆盖常见 Rust 语言阅读知识；执行器实现、复杂 unsafe 健全性证明等属于后续专修，遇到时会给出边界。

示例使用 Rust 1.95.0 / edition 2024，无需外部 crate。进入 examples/rust-reading 后运行 cargo run --offline --example l01，或执行 cargo test --offline。详细运行方法见 运行说明；换电脑时参考 官方安装说明。
