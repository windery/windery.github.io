struct 与方法接收者

从 self 的形式看出方法是否消耗对象。

描述数据与失败建议 8–15 分钟

先建立一个判断方法

struct 把命名字段组合成新类型，impl Type 为它定义关联函数和方法。Self 指当前实现的类型；小写 self 是方法的接收者。没有 self 参数的关联函数常用 Type::new() 形式调用。

&self 共享借用，&mut self 独占借用，self 按值接收。点调用通常会自动借用或解引用接收者，因此“看见对象.method()”本身不足以判断对象是否被消耗，要看签名。

依据：Rust 官方文档 · 对应章节

先预测，再运行

先说出输出、关键值的类型，以及它们是否仍可使用，再展开结果。

examples/l10.rs / Rust 2024
struct Counter {
    value: u32,
}
impl Counter {
    fn new() -> Self {
        Self { value: 0 }
    }
    fn increment(&mut self) {
        self.value += 1;
    }
    fn value(&self) -> u32 {
        self.value
    }
    fn into_value(self) -> u32 {
        self.value
    }
}
fn main() {
    let mut counter = Counter::new();
    counter.increment();
    println!("{}", counter.value());
    println!("{}", counter.into_value());
}
展开预期输出与阅读解析
1
1
  1. new 是关联函数；increment 与 value 是方法。
  2. into_value 按值接收 Counter，调用后 counter 不可再使用。into_ 是常见命名惯例，真正证据是 self 签名。

运行：在 examples/rust-reading 中执行 cargo run --offline --example l10。所有主示例均为完整程序；练习里的失败片段会明确说明。参见 下载与运行说明。

常见误读Rust 的 impl 不是类继承声明。结构体更新语法 ..old 也可能移动 old 的部分字段，不等于自动深拷贝。

检查你的判断

哪一种接收者在本例中消耗对象？

查看完整判断依据

按值接收。Counter 没有实现 Copy，self 按值传入时移动所有权。

合上解释，自己说一遍

若希望清零后继续使用 counter，reset 应接收 self、&self 还是 &mut self？写出实现。

完成后查看参考解析

fn reset(&mut self) { self.value = 0; }。需要独占借用以修改字段，但不应消耗对象。
