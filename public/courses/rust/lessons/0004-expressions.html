表达式、分号与返回值

判断一个代码块最终产生什么值。

读出基本语法建议 8–15 分钟

先建立一个判断方法

Rust 中 if、match 和花括号块都可以是表达式。块末尾没有分号的表达式通常成为块的值；把分号加上，常会把“返回一个值”变成“执行语句后返回 ()”。

函数可以用 return 提前返回，也可以由函数体的尾表达式返回。调用的参数类型必须符合签名；阅读函数时先找尾表达式，再找 return 和稍后会学的 ?。

依据：Rust 官方文档 · 对应章节

先预测，再运行

先说出输出、关键值的类型，以及它们是否仍可使用，再展开结果。

examples/l04.rs / Rust 2024
fn plus_one(n: i32) -> i32 {
    let increment = {
        let base = 0;
        base + 1
    };
    n + increment
}
fn main() {
    println!("{}", plus_one(4));
}
展开预期输出与阅读解析
5
  1. increment 的值是块尾的 base + 1，即 1。
  2. plus_one 的尾表达式 n + increment 没有分号，因此提供 i32 返回值。

运行：在 examples/rust-reading 中执行 cargo run --offline --example l04。所有主示例均为完整程序；练习里的失败片段会明确说明。参见 下载与运行说明。

常见误读写 n + increment; 会让本例函数体产生 ()，与 -> i32 不匹配。return n + increment; 则是合法的显式返回。

检查你的判断

给函数最后的 n + increment 添加分号会怎样？

查看完整判断依据

编译失败。声明要 i32，实际函数体变成单位值 ()，因此类型不匹配。

合上解释，自己说一遍

手写一个绝对值函数的思路：使用 if 表达式返回两个分支之一，不用 return。先只考虑 -10 到 10。

完成后查看参考解析

fn abs_small(n: i32) -> i32 { if n < 0 { -n } else { n } }。两个分支都产生 i32。范围限定是因为 i32::MIN 的相反数无法表示为 i32。
