从哪里开始读一个 Rust 项目

在项目中找到入口，并把函数签名翻译成人话。

读出基本语法建议 8–15 分钟

先建立一个判断方法

先看 Cargo.toml，确认包名、edition 与 dependencies；再找 src/main.rs（常见可执行入口）或 src/lib.rs（常见库入口）。一个 package 可以有多个 crate，crate 是编译单元，不要把每个 .rs 文件都理解成一个包。

阅读函数先问四件事：接收什么类型、返回什么类型、是否改变数据、可能在哪提前退出。暂时不认识实现细节，也可以从签名开始建立判断。fn 是函数，箭头后是返回类型，感叹号通常提示宏调用。

本课程采用 Rust 2024 edition，例子用本机 rustc 1.95.0 验证。edition 是语言兼容规则，不等于编译器版本；Cargo.toml 中写 edition = "2024"。不用先安装框架。

依据：Rust 官方文档 · 对应章节

先预测，再运行

先说出输出、关键值的类型，以及它们是否仍可使用，再展开结果。

examples/l01.rs / Rust 2024
fn double(n: i32) -> i32 {
    n * 2
}
fn main() {
    let answer = double(21);
    println!("{answer}");
}
展开预期输出与阅读解析
42
  1. fn double(n: i32) -> i32：输入一个 32 位有符号整数，输出同类型整数。
  2. main 的签名没有箭头，返回单位类型 ()。它调用 double，再打印结果。
  3. 本课程示例可在 examples/rust-reading 下运行：cargo run --example l01。cargo check 只检查；cargo test 执行测试；cargo doc --open 生成并打开文档。

运行：在 examples/rust-reading 中执行 cargo run --offline --example l01。所有主示例均为完整程序；练习里的失败片段会明确说明。参见 下载与运行说明。

常见误读不要把 println! 当成普通函数，也不要把 use 当成下载依赖。下载和构建依赖由 Cargo 管理。

检查你的判断

例子中 double 的返回值属于哪类？

查看完整判断依据

整数类型。签名中的 -> i32 明确给出返回类型。函数名本身不能证明类型。

合上解释，自己说一遍

不看实现，只读 fn enabled(count: usize) -> bool。说明输入与输出；然后找到课程示例的 Cargo.toml。

完成后查看参考解析

输入 count 的类型为 usize，输出 bool。usize 是平台指针宽度的无符号整数，常用于长度和索引。签名没有引用参数，不能由此推断它一定没有全局副作用。
