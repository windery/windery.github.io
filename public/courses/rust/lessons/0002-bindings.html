let、mut 与遮蔽

区分重新赋值与创建同名的新绑定。

读出基本语法建议 8–15 分钟

先建立一个判断方法

let 默认创建不可变绑定。let mut 允许对该绑定重新赋值；这不意味着后续赋值可以改变它的静态类型。Rust 可以推断许多局部类型，但函数参数一般需要明确标注。

再次写 let 可以遮蔽旧名字：这是新的绑定，允许改变类型。阅读时沿作用域追踪名字，而不是假定同名始终代表同一个变量。const 必须标注类型，初始化受常量求值规则限制。

依据：Rust 官方文档 · 对应章节

先预测，再运行

先说出输出、关键值的类型，以及它们是否仍可使用，再展开结果。

examples/l02.rs / Rust 2024
fn main() {
    let text = "12";
    let text: usize = text.len();
    let mut count = text;
    count += 1;
    println!("{count}");
}
展开预期输出与阅读解析
3
  1. 第一个 text 是字符串切片引用；第二个 text 是长度 2。
  2. count 被推断为 usize；+= 修改现有绑定，而第二个 let text 创建新绑定。

运行：在 examples/rust-reading 中执行 cargo run --offline --example l02。所有主示例均为完整程序；练习里的失败片段会明确说明。参见 下载与运行说明。

常见误读mut 不是“动态类型开关”。let mut n = 1; n = "one"; 无法通过类型检查。

检查你的判断

第二条 let text 做了什么？

查看完整判断依据

创建绑定。它创建新绑定并遮蔽旧名字，没有修改字符串本身。

合上解释，自己说一遍

把第二条 let 改成 text = text.len();，预测能否编译，并说出两方面原因。

完成后查看参考解析

不能。旧 text 不可重新赋值，而且旧类型 &str 与新值 usize 不匹配。只添加 mut 不能解决类型不匹配。
