读懂基础类型和复合类型

从类型标注区分数值、字符、元组和数组。

读出基本语法建议 8–15 分钟

先建立一个判断方法

i32、u64 的数字表示位宽；usize 与平台指针宽度相同。f64 是常用浮点类型。bool 只有 true/false，条件没有通用“真值转换”。char 是 Unicode 标量值，不等同于用户看到的完整字形。

(i32, bool) 是固定位置的异构元组，[i32; 3] 是固定长度的同类型数组。数组长度是类型的一部分。() 是零元素元组，也叫单位类型；没有有用返回值的函数常返回它。

依据：Rust 官方文档 · 对应章节

先预测，再运行

先说出输出、关键值的类型，以及它们是否仍可使用，再展开结果。

examples/l03.rs / Rust 2024
fn main() {
    let pair: (i32, bool) = (7, true);
    let numbers: [i32; 3] = [2, 4, 6];
    let (value, enabled) = pair;
    println!("{} {} {}", value, enabled, numbers[1]);
}
展开预期输出与阅读解析
7 true 4
  1. 元组可用 .0/.1 访问，也可解构为局部名字。
  2. numbers[1] 是第二项；直接索引越界会 panic，安全查询可使用 get。

运行：在 examples/rust-reading 中执行 cargo run --offline --example l03。所有主示例均为完整程序；练习里的失败片段会明确说明。参见 下载与运行说明。

常见误读整数除法不会自动产生小数；5 / 2 在整数上下文中得到 2。不要依赖溢出时的默认表现来实现业务逻辑。

检查你的判断

[u8; 4] 中的 4 表示什么？

查看完整判断依据

数组长度。u8 表示元素类型；分号后常量 4 表示数组长度。

合上解释，自己说一遍

解释 (&str, [u8; 2], bool) 的三个位置；预测 (5 / 2, 5.0 / 2.0) 的值。

完成后查看参考解析

分别是字符串切片引用、两个 u8 的数组、布尔值。后一个表达式得到 (2, 2.5)。&str 会在借用与切片课中细讲。
