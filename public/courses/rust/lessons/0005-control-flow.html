先建立一个判断方法

if 的条件必须是 bool；作为值使用时，各分支需要得到兼容的类型。loop 可以无限循环，break value 可以给该 loop 表达式提供值。while 与 for 的普通退出不使用这种带值 break。

for item in iterable 遍历可迭代对象。0..3 不含 3，0..=3 包含 3。循环是否消耗集合取决于遍历的是集合本身还是它的引用，不能只看 for 这个关键词。

依据：Rust 官方文档 · 对应章节

先预测，再运行

先说出输出、关键值的类型，以及它们是否仍可使用，再展开结果。

examples/l05.rs / Rust 2024
fn main() {
    let mut total = 0;
    for n in 1..=3 {
        total += n;
    }
    let found = loop {
        if total > 5 {
            break total;
        }
        total += 1;
    };
    println!("{found}");
}
展开预期输出与阅读解析
6
  1. 1..=3 依次产生 1、2、3，total 为 6。
  2. 第一次 loop 迭代直接 break 6，found 接到这个值。

运行：在 examples/rust-reading 中执行 cargo run --offline --example l05。所有主示例均为完整程序；练习里的失败片段会明确说明。参见 下载与运行说明。

常见误读if 1 { ... } 不合法；需要写出明确的布尔条件。continue 只开始下一轮，不退出循环。

检查你的判断

把 1..=3 改成 1..3，最终输出是？

查看完整判断依据

数字六。for 结束时是 3，但 loop 会递增到 6 才退出。要追踪整个程序，而不只看第一段循环。

合上解释，自己说一遍

解释嵌套循环中 break 与 break 'outer 的差异，并说明标签 'outer 是否是生命周期。

完成后查看参考解析

无标签 break 退出最内层循环；break 'outer 退出名为 'outer 的外围循环。循环标签也使用单引号，但不是生命周期参数，要结合语法位置判断。
