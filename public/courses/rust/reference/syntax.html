符号与类型速查

先看符号所处的位置：表达式、类型、模式可能不是同一含义。

写法读法相关课
let mut x: T = value;创建可重新赋值的 T 绑定。02
fn f(x: T) -> U输入 T，返回 U。01 / 04
() / !单位类型 / 永不正常返回的类型。03 / 12
&x / &mut x共享借用 / 独占借用表达式。07
&T / &mut T共享引用类型 / 独占引用类型。07
*r解引用；在模式里需按模式规则另读。14
String / &str拥有文本 / 借用 UTF-8 文本视图。08 / 09
Vec<T> / &[T]拥有动态序列 / 借用序列切片。08 / 14
[T; N] / (T, U)固定数组 / 异构元组。03 / 15
.. / ..=范围不含末端 / 包含末端；模式中 .. 也可省略字段。05 / 28
Type::new() / x.method()关联项调用 / 方法调用。10
a::b / ::<T>路径分隔 / 表达式中的显式泛型实参。13 / 18
Option<T> / Result<T, E>可能缺失 / 成功或失败。11 / 13
expr?成功拆包，失败提前返回；依上下文规则。13
pattern => exprmatch 分支。12
if let / let ... else单模式分支 / 提前处理不匹配。12
T: A + B / where T: A要求同时满足约束 / 后置约束子句。16
&'a T / T: 'a引用有效期 / 类型满足的存活约束。17 / 33
impl Trait / dyn Trait泛型或隐藏具体类型 / 动态 trait 对象。26
Item = U / <T as A>::Item关联类型等式约束 / 完全限定关联类型。27
|x| expr / move || expr闭包 / 按值捕获环境的闭包。19
async / .await创建异步计算 / 等待其结果的潜在暂停点。25
name! / #[attr]宏调用 / 属性，不是所有属性都是宏。29
/// / //!为后续项写文档 / 为外围项写文档。31
pub / pub(crate)公开 / 仅当前 crate 内公开。18
unsafe / extern "C"额外安全义务 / 外部 ABI 边界。30

不确定某个宏或属性来自哪里时，先查 Cargo.toml 与 use。常见库名是依赖线索，不属于 Rust 语言关键字。
