字节码：用 javap 看编译器替你做了什么

自动装箱、字符串拼接、比较运算在字节码里各是什么样。

JVM 运行时：从源码到运行建议 15–20 分钟

先建立一个判断方法

javac 不做优化，只把语法糖展开成 JVM 指令。所以 javap -c -p 是一面诚实的镜子：源码里看不见的方法调用、隐式转换和临时变量，在字节码里都会写出来。性能优化是运行时 JIT 的工作（下一节会讲）。

JVM 是栈式虚拟机。读字节码时，记住三类指令就能看懂大半：iload、aload、bipush 把值压入操作数栈；istore、astore 把栈顶写回局部变量槽；invoke* 从栈上取参数调用方法，if_* 比较栈顶的值并跳转。

源码字节码里实际发生的事
Integer a = 127;invokestatic Integer.valueOf：自动装箱就是一次静态方法调用
a == b（两个 Integer）if_acmpne：比较的是引用，不是数值
"n=" + nJDK 9 起是 invokedynamic makeConcatWithConstants（JEP 280），不再固定编译成 StringBuilder
lambda 表达式invokedynamic + LambdaMetafactory，首次执行时才生成实现类

Integer.valueOf 会对 -128 到 127 返回缓存中的同一个对象（上限可用 -XX:AutoBoxCacheMax 调大），范围外每次新建。这正是“小整数用 == 碰巧对、大整数用 == 就错”的根源。

依据：JVM 规范第 6 章 · 指令集 · JDK 21 · javap 工具文档

先预测，再运行

先预测四行输出，再想一想：label 方法里的字符串拼接会编译成什么？

java-depth/src/L03.java / JDK 21
public class L03 {
    static String label(int n) {
        return "n=" + n;
    }

    public static void main(String[] args) {
        Integer a = 127, b = 127;
        Integer c = 128, d = 128;
        System.out.println(a == b);
        System.out.println(c == d);
        System.out.println(c.equals(d));
        System.out.println(label(3));
    }
}
展开实际输出与阅读解析
true
false
true
n=3
  1. 四次赋值都编译成 Integer.valueOf。127 落在缓存范围内，a 和 b 指向同一个对象；128 不在范围内，c 和 d 是两个不同的对象。
  2. == 编译成 if_acmpne，只比较引用，所以第二行是 false；equals 比较数值，第三行是 true。
  3. label 方法只有三条指令：加载参数、一条 invokedynamic makeConcatWithConstants、返回。拼接策略在运行时第一次调用时由 StringConcatFactory 决定。

常见误读“javac 会把 + 拼接优化成 StringBuilder”是 JDK 8 时代的说法。现在看到的是 invokedynamic，具体策略由运行时决定。判断这类问题时，以当前 JDK 的 javap 输出为准，不以旧文章为准。

检查你的判断

Map<String, Long> 里存的计数用 map.get("a") == map.get("b") 比较，两个计数都是 1000。结果通常是什么？

查看完整判断依据

false，因为比较的是两个不同的 Long 对象。Long.valueOf 同样只缓存 -128 到 127。1000 装箱后是两个不同的对象，== 比较引用得到 false。应使用 equals，或先拆箱成 long 再比较。

合上解释，自己说一遍

不运行 javap，说出 for (String s : list) { ... } 编译后大致会出现哪些方法调用；如果 list 换成 String[] 呢？

完成后查看参考解析

对 Iterable，增强 for 展开为 invokeinterface List.iterator，循环中反复调用 Iterator.hasNext 和 Iterator.next，再用 checkcast String 把 Object 转回 String（泛型擦除的痕迹）。对数组，展开为基于下标的循环：arraylength、aaload 与 if_icmpge，循环本身不调用任何方法。可以用 javap 自己核对。
