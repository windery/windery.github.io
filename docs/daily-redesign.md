# AI 日报编辑精选改版

## 范围与内容契约

- 日报独立居中正文，桌面与手机共用轻目录；首屏结论最多三条，归档展示标题/摘要。未修改课程或项目阅读布局。
- `editorialVersion: 2` 支持按影响编排、少讯日短刊、无价值栏目省略。旧版两期与旧样例保留原文，发布器继续接受旧格式。
- 新版验证必需栏目/顺序、1–3 条重点、逐源 coverage、六项编辑内容、稳定事件注释、证据链接与本期 URL/事件去重。原文事实、证据等级、跨 14 天事件去重和目录覆盖完整性仍需生成任务核实，不能由字段齐全推导质量达标。
- 发布时间未知必须注明未知；抓取时间不是发布时间。未实测必须说明，推广描述不是性能结论。
