# AI 日报编辑精选改版

状态：2026-10-17 已落到 main。当前生产形态是**单刊 v2**；四篇独立文章方案保留为后续，不阻塞本轮。

## 范围与内容契约

- 日报详情页 720px 单栏正文 + 右侧目录，索引页桌面带日期栏、窄屏单列；首页有「最新日报」入口。
- `editorialVersion: 2`：标题只讲一件事、不带日期前缀；摘要一句；`highlights` 1–3 条；`tags` 2–3 个；`topics` 只供飞书；`coverage` 只放 frontmatter。
- 正文顺序：重点解读（1–3 条）→ 工具与实践（0–1 条）→ 简讯（0–3 条）→ 深读推荐（0–1 条）。每条故事用 H3 + 2–4 个自然段，禁止「变化/影响/建议/限制/证据/发布时间」字段表；证据链接贴事实，`<!-- event: slug -->` 记录稳定事件 ID。
- 公开正文不写「口播选题」「采集说明」；发布器仍接受旧格式，旧两期保留原文（补了摘要与标签，去掉开头采编日志）。
- 发布时间未知必须注明未知；抓取时间不是发布时间。未实测必须说明，推广描述不是性能结论。

## 验收

`npm run build` 先跑 `scripts/check-daily.mjs`，再构建、Pagefind、站内链接与私有路径扫描；`npm test` 在临时 Git 仓库测试发布/补抓/飞书 mock；`deploy.yml` 运行 `npm test`，`daily-freshness.yml` 每天检查线上最新一期是否超过 2 天。

桌面 1440×900、手机 390×844 与 320×844 用 DOM 几何验收：正文无横向溢出；日报详情首个故事在 449px（桌面）/512px（手机）/541px（320），进入首屏；索引 390px 单列，日期栏隐藏。
