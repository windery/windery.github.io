# 四篇样例内容自审

审查对象：`daily-samples/` 下四份虚构样例、四篇设计文档及样例验收方式。结论：未通过内容验收。四篇独立文章的交付形态已明确，但现有样例只能展示结构，不足以证明内容符合要求。

本次只审查本地文本与已确认需求，未重新采集新闻、核验外部事实或评估真实项目。下面引用均来自样例，不代表真实事件。

## 发现

| 优先级 | 位置与原文 | 问题及影响 | 修正要求 |
|---|---|---|---|
| 高 | 新闻导语：“一个主流模型家族完成换代；一项接口迁移已经有明确期限” | 厂商、模型、接口、时间都缺失。摘要脱离标题与正文无法独立传递消息。 | 首次出现明确主体名称与具体动作；摘要保留最重要的事实，不能把名称抽象掉。 |
| 高 | 新闻：“主流模型换代会改变工具平台的默认选择” | 从模型发布跳到第三方平台变更，缺少因果证据；不是所有平台都会同步更换默认模型。 | 区分已发生的事件与可能影响；第三方平台变更需单独公告，不能由模型发布推导。 |
| 高 | 新闻接口条目：“有明确期限”“应先确认自己的 SDK” | 没写谁的哪个接口、哪天停用、受影响版本，反而先给泛化建议；读者无法判断自己是否受影响。 | 先交代接口名称、停用日期、受影响对象与官方替代路径，再给有针对性的建议。 |
| 高 | 四篇多处：“正式稿应给出”“来源位置”“待真实链接” | 把编辑说明放进读者正文，未交付可阅读的完整文章。虚构样例无法检验真实取舍与证据组织。 | 编辑规范与文章分开；下一轮内容验收必须用真实材料，不再将占位模板当质量样稿。 |
| 高 | 工具：“假设其实现分三步”及通用方式对比表 | 没有实际读过项目关键实现；比较的是通用思路，不是具体工具。文章换成另一项目名仍大致成立。 | 明确 owner/repo、版本或提交、关键实现与实际限制；给出具体使用链路和有依据的替代方案比较。 |
| 高 | 方法：“原文位置：一篇近 30 天内……博客” | 没有作者、文章名、日期和作者的论证，主体是编辑自拟的一般建议，未满足“一篇博客精读”。 | 围绕一篇具名原文展开：作者问题、核心主张、具体案例、方法步骤和局限；编辑补充明确归属。 |
| 中 | 口播：“新模型发布后，你的旧评测还够用吗？”等三张卡 | 切口可用于大量日期，没有具体人物、工具、案例或新增信息；提纲是话题顺序，尚不足以支撑选题判断。 | 卡片至少绑定一个具体事实或案例，明确主张、证据与为什么值得现在讲；技术常青题也要有具体素材。 |
| 中 | 四篇反复出现“自己比较”“不保证”“未实测”等提醒 | 限制说明占据本应用于解释能力、工作方式和案例的篇幅；谨慎措辞没有补上内容缺口。 | 仅写与该条结论相关的具体限制，一处讲清；先让读者获得信息，再解释证据边界。 |
| 中 | 新闻样例将模型发布迅速转为迁移与评测建议 | 用户要了解模型、技术、产品和行业发生了什么；样例过早套入工程风险检查，新闻阅读目的被弱化。 | 新闻先回答“谁发生了什么重要变化”，说明实际新增能力或行业影响；只有必要时给行动建议。 |
| 中 | 四篇拆分后，仍共享相同的“不要盲信、要做验证”结论 | 文件独立，但各篇读者收获区分不足。 | 新闻提供新事实，工具提供具体项目理解，方法提供原文方法，口播提供可讲的主张与案例。 |
| 中 | 访谈先讨论数量、规则、通知等细节，再请求批准虚构样例 | 用户已经给出了基本目标，但编辑没有用真实稿证明理解；让用户反复指出基础写作问题。 | 基础编辑质量由编辑先自审，问题只用于真正的偏好取舍；先提供真实独立样稿，再验收实现方案。 |

## 可以直接落实的编辑检查

1. **主体检查**：只读标题和导语，能否识别谁、哪个产品或项目、做了什么？“厂商”“某模型”“该平台”只允许在已有明确指代时使用。
2. **新增事实检查**：与过去相比到底多了什么、变了什么？无依据时删掉升级幅度、默认行为或因果判断，不能用形容词补齐。
3. **独立阅读检查**：不打开其他三篇，也能理解本文事实、对象和结论；跨篇链接仅补充阅读。
4. **替换名称检查**：换成另一个模型、项目或作者，正文是否仍然成立？若是，补充其独有的机制、案例、参数、条件或论证。
5. **证据检查**：关键结论能回到具名的一手材料；评测明确谁测的、测了什么和条件。不强制本站实测，也不将未实测当作缺少文档与代码依据的理由。
6. **读者正文检查**：不存在“正式稿应”“待补链接”等编辑任务或占位词；来源、日期、关键限制已经填实。
7. **价值检查**：新闻给出不该错过的具体事实；工具让读者判断是否适合自己；方法让读者掌握该作者的具体做法；口播让用户判断是否值得制作。

## 下一轮验收方式

- 四份虚构样例保留为失败样例，显式标记未通过，不以替换几个词的方式宣布修复完成。
- 使用真实且已核实的材料分别写四篇独立样稿。若使用历史材料，标注原始日期与回放窗口，不包装成当日新消息。
- 新闻写出具名主体与新增事实；工具实际读文档和关键实现；方法完整阅读一篇具名原文；口播依托真实素材形成可讲的观点。
- 编辑先按上述检查完成自审，再请用户评审内容。当前尚未获得进入生产实现的确认。
