# AI 日报参考与落地规则

核对日期：2026-10-15。本文区分已观察到的参考特点与本项目的编辑设计，不转载参考内容，也不将参考作者的实测归为本站实测。

## 参考核对

- [TLDR AI，2026-10-14](https://tldr.tech/ai/2026-10-14)：本次浏览工具返回页面不可访问；本机 `curl` 返回域名解析失败。未获得正文或页面截图，不能声称已核实该期栏目、视觉尺寸、文章数量或阅读时长。用户指定的“清晰阅读层次”作为设计目标保留，以下规则不冒充对该期页面的复刻结论。
- [Simon Willison’s Weblog](https://simonwillison.net/)：首页以日期组织不同长度的条目，配有原文链接、时间、标签和永久链接；短摘记与长文入口共存。技术评论会补充具体例子，区分观察与推测，并指出比较条件、限制或待确认之处。可借鉴的是有依据的判断与不等长的信息密度，而非照搬其时间线。（本次仅阅读该第一方首页，未独立核实其链接中的新闻事实。）

## 本项目采用的原创阅读结构

以下是针对本站任务的设计建议，不是参考页面的逐项事实描述。

1. **首屏：先给判断。** 日期、能概括当日变化的标题、一句导读，以及最多三条重点结论。每条结论可跳到对应解读；没有足够证据时可以少于三条。
2. **重点解读：把篇幅给影响。** 以事件为单位，按对读者决策的影响排序，不按来源逐个平铺。标题先交代具体变化，正文说明影响对象、可采取的行动和限制，并链接原始证据。
3. **工具与实践：给可执行入口。** 只收录有明确用途的工具或技术方法，交代适用场景、前提与验证入口。未运行就写“可按文档验证”，不能写成“实测有效”。
4. **简讯：短而完整。** 一两句话说明变化与相关人群，不为数量扩写。与重点解读同一事件的消息合并补充，不重复占条。
5. **深读与口播选题：降低优先级。** 深读解释值得投入时间的理由；口播选题放在主阅读流程之后，避免选题文案盖过技术信息。
6. **文末：留下可追溯性。** 显示采集窗口、覆盖与缺口说明。发布时间与采集时间分开标注，不把抓取时间充当发布时间。

## 编辑门槛

- 每条重点至少回答：发生了什么变化、影响谁、为何现在值得关注、读者可做什么、证据有什么边界。
- 发布方声明、第三方观察、编辑推断、本站实测分别表述。数据保留单位、基准和条件；无法核实的效果不进入标题或首屏。
- 优先链接公告、文档、代码、论文等原始材料；聚合页可作线索，不代替核心证据。转载与多个 URL 指向同一发布时按事件合并。
- 少讯日允许只保留少量重点，空栏目隐藏；不为补足固定数量收录低价值条目。
- 首屏摘要是全文的编辑浓缩，不能只截断正文，也不能承诺正文没有支持的结论。

## 版式验收

- 日报使用独立、适中宽度的正文；桌面仅保留轻目录，手机改为紧凑导航。标题、摘要、正文、来源元数据有明确层级。
- 以留白、字重和少量强调色区分重点；正文不全部装成同权重卡片，避免每个段落都像操作面板。
- 归档展示标题与短摘要，帮助读者决定打开哪一期；旧日报缺少新字段时应正常展示。
- 检查桌面与手机、明暗主题、长标题换行、来源链接、目录与重点锚点；采集说明不得挤占首屏主要阅读区域。
