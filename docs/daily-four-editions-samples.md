# 四篇独立文章样例

> 内容自审未通过：以下文件仅为虚构结构草稿，不作为质量验收样稿。问题与修正标准见 [内容自审](daily-editorial-self-review.md)。

每个链接对应一篇独立文章，各自有标题和完整正文。四篇都发布到学习站，并合并为一条每日通知。

所有样例均为虚构内容，仅供结构评审。

## 汇总消息示意

AI 日报｜日期

- 新闻：一句摘要 → 新闻篇独立链接。
- 工具：深挖项目及用途 → 工具篇独立链接。
- 方法：今日方法及适用场景 → 方法篇独立链接。
- 口播：选题标题 → 飞书口播篇独立链接。

成功篇目照常交付，汇总注明缺项与故障；正常采集但四篇均无合格内容时静默，有故障则告知。
