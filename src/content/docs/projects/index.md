围绕一个开源项目的成系列文章，讲怎么用、怎么实现，用来学技术。

- [pbakaus/impeccable](/projects/impeccable/overview/)：为 AI 编程助手提供设计方法、界面检测和浏览器迭代工具。
- [windery/agent-to-feishu](/projects/windery-agent-to-feishu/overview/)：三个独立技能，将会话与项目知识整理为飞书文档或公开学习站文章。
- [mattpocock/skills](/projects/mattpocock-skills/overview/)：把需求澄清、领域建模、拆票、测试和审查组织成可组合的 Agent 技能。
- [harry0703/MoneyPrinterTurbo](/projects/harry0703-moneyprinterturbo/overview/)：给一个主题，自动完成文案、配音、字幕、素材和剪辑，输出短视频。
- [debpalash/VoiceStudio](/projects/debpalash-voicestudio/overview/)：在本机完成声音克隆、声音设计、视频配音和语音转写，可通过 API 与 MCP 调用。
- [vectorize-io/hindsight](/projects/vectorize-io-hindsight/overview/)：给 AI Agent 加长期记忆：写入时抽取事实，多路检索记忆，再带着记忆推理回答。
- [paperclipai/paperclip](/projects/paperclipai-paperclip/overview/)：把 Claude Code、Codex 等 AI Agent 组织成一家公司，统一派活、唤醒、控预算和审批。
