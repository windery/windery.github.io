## 写代码

### [Tw93 精简 Skills 和项目上下文，附可复制提示词](https://x.com/HiTw93/status/2120410995592139253)

作者删掉了近三分之一 Skills 并优化各项目上下文，认为模型变强后应常裁剪给模型的信息。他给出一段提示词，让 Agent 先盘点常驻内容并列清单确认，再按修、删、挪、改写、保留处理。 （来源：X List）

### [Matt Pocock：领域驱动设计让 Agent 写代码效果惊人](https://x.com/mattpocockuk/status/2120503390333768170)

Matt Pocock 说他的课程里最让学员惊讶的不是 Agent 部分，而是领域驱动设计：建立通用语言，与 Agent 一起使用，并据此重构代码，效果非常好。 （来源：X List）

### [Martin Fowler：把测试变成数据来约束 AI 生成的代码](https://martinfowler.com/articles/tests-as-data.html)

当 AI 同时写生产代码和测试代码，测试的保障作用会减弱。文章主张开发者成为 AI 的客户，客户测试成为人与 AI 之间的主要契约，并把契约放进测试数据而非测试代码，更易保护。 （来源：Martin Fowler）

### [Kaku：为 AI 编程设计的开源 Mac 终端](https://x.com/HiTw93/status/2120531568179749198)

同时跑多个 Agent 时，标签页会在 Agent 需要你时亮点，Cmd+J 直接跳转；手机上的远程页面可查看每个标签页里 Agent 的状态。 （来源：X List）

### [Geoff 演讲：安全成为新瓶颈，靠工程而非 AI 解决](https://x.com/GeoffreyHuntley/status/2120602355066659231)

攻击者会自动扫描并利用新提交的代码。演讲主张让安全事件响应变快，交付也会随之变快，答案是工程本身而不是 AI。 （来源：X List）
