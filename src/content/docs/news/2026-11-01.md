## 简报

- **Chris Tate 发布 agent-desktop**：Chris Tate 发布 agent-desktop，为 coding agent 提供跨 macOS、Windows 与 Linux 的电脑操作能力，支持多个 agent 各自携带独立光标在后台并行操作电脑。 [来源](https://x.com/ctatedev/status/2116323148706771302)
- **Alma Relay Server 开源**：yetone 开源 Alma Relay Server，支持通过 Cloudflare Workers 免费套餐或 Docker 单条命令自建中继服务器远程控制电脑上的 Alma，传输采用端到端加密。 [来源](https://x.com/yetone/status/2116599592930488707)
- **Magpie 改用 Claude Code TUI 实现**：Magpie 将其 Claude Code Provider 的默认实现由 claude -p 改为直接调用 Claude Code TUI，同时保留可配置切回原方案的选项。 [来源](https://x.com/yetone/status/2116525328390823955)
- **Mario Zechner 发布 pi-schema**：Mario Zechner 发布 JSON Schema 构建与校验库 pi-schema，基于闭包机制实现，可在包括禁用 eval() 在内的任意 JavaScript 环境中运行。 [来源](https://x.com/badlogicgames/status/2116653884362097081)
- **baoyu-design 新增局域网团队共享**：baoyu-design 新增局域网团队共享功能，支持基于本地 IP 和端口分享并提供只读、评论、编辑三级权限与实时同步，其 DeepSeek Harness 插件也同步更新支持。 [来源](https://x.com/dotey/status/2116623097839149231)
- **LlamaIndex 发布文档解析测试集 BooBench**：LlamaIndex 发布包含 179 个测试页面的基准测试集 BooBench，用于检测文档解析工具与视觉语言模型在特定页面排版下陷入字符或行重复输出的失效现象。 [来源](https://www.llamaindex.ai/benchmarks/boobench)
- **Pierre-Loic Doulcet 发布开源实验 Autotoken**：Pierre-Loic Doulcet 发布黑客松开源实验项目 Autotoken，探索将 agent 中重复执行的工作转化为可复用程序。 [来源](https://x.com/hexapode/status/2116390868878053521)
