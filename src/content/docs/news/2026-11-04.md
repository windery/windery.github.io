## Agent

### [video-to-skill：让 AI 看视频教程自动生成 Skill](https://x.com/i/status/2116820754734170427)

这个 Skill 给它视频教程，它会听讲解、看关键画面，把步骤做成可复用的 Skill，还会尝试在沙箱执行这些步骤，无法验证的会标出。 （来源：X 搜索）

### [Warp 的软件工厂：调模型、减少子 Agent，每个 PR 降本](https://x.com/latentspacepod/status/2117721636195663898)

Warp 的 Zach Lloyd 介绍开源云端软件工厂做法，称调优模型并减少冗余 subagent 后，每个 PR 成本从约 80 美元降到 15 到 20 美元，吞吐提升 40%。 （来源：X List）

### [团队共享 Agent 会话，能学到别人怎么驱动 Agent](https://x.com/patrickerichsen/status/2117699697163047045)

团队改用互相可见提示词的多人会话后，作者发现大家都会说蠢话，也能从队友驱动 Agent 的方式中学到很多，比如直接去看设计同事如何用 Agent 做原型。 （来源：X List）

### [本地长期编排线程加软件工厂的 Agent 组合思路](https://x.com/mattpocockuk/status/2117570433134313951)

Matt Pocock 考虑组合两种做法：一个覆盖单一领域的本地长期编排线程，连接带沙箱实现者的软件工厂；编排者通过 CLI 管理线程、运行 retro、建立定时任务。 （来源：X List）
