## 简报

- **LlamaIndex 为 Extract 推出 Max Effort 设置**：LlamaIndex 为 Extract 的 agentic_plus 推出 max effort 设置，可在提取复杂图表等视觉细节时按需提高分辨率并采用可变计费，官方测试显示其在 ExtractBench Pro 上的 Value F1 从 77.7 提升至 94.3。 [来源](https://www.llamaindex.ai/blog/introducing-max-effort-for-extract-agentic-plus)
- **Armin Ronacher 发布 lineread**：Armin Ronacher 开源实验性 Rust 项目 lineread，由 AI coding agent 基于针对 GNU Readline 8.3 构建的黑盒测试与接口声明重新实现了 Readline C 接口。 [来源](https://github.com/mitsuhiko/lineread)
- **pi 移除 TypeBox 依赖**：Mario Zechner 宣布 pi 移除了 TypeBox 依赖，但仍允许开发者在工具参数等场景中继续使用 TypeBox。 [来源](https://x.com/badlogicgames/status/2116866026726138058)
