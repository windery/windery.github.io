## 写代码

### [Claude Code v2.1.319：auto 模式在网关后的行为调整](https://github.com/anthropics/claude-code/releases/tag/v2.1.319)

更新说明：关闭遥测或功能开关时（含 LLM 网关后），auto 模式中服务端无法检查的调用会被询问或拒绝；设置 CLAUDE_CODE_AUTO_MODE_SERVER=0 可继续使用内置分类器，=1 可在网关后开启服务端检查。 （来源：Claude Code releases）

### [大模型持续强化小检索模型，用于 Agent 记忆](https://x.com/dbreunig/status/2118757661961494902)

### [循环工程：让 spec 成为 Loop Agent 内部细节，目标由 Agent 设定](https://x.com/guyingjie129/status/2118745908401836498)

作者认为循环工程的最佳实践是人类输入保持粗糙原始，spec/task 作为 Agent 内部细节，减少中间材料。唯一例外是目标：让 Agent 聊完后自己设置，人再审核是否符合预期，不符则重来。 （来源：X List）

### [软件工厂概念被泛化，关键部分难以通用](https://x.com/dexhorthy/status/2118718628627464571)

dex 认为“软件工厂”一词正被语义稀释；其“自动化更多事情”的思路仍有用，但技术栈、lint、测试、预览等各家差异大，难以用产品通用解决，所以很多人觉得被厂商忽悠。 （来源：X List）

### [手动驱动循环，用推理产出不依赖模型行为的确定结果](https://x.com/GeoffreyHuntley/status/2118668987269611937)

Geoffrey Huntley 称自己仍手动驱动循环，每周推理花费 4.3 万美元，认为不需要工厂而需要好工程：用推理创造不依赖模型行为的确定结果，模型变强后自动受益，无需担心评测。 （来源：X List）

### [把 Agent 空间当 Slack 频道用，线程承载具体任务](https://x.com/thorstenball/status/2118773921021370568)
