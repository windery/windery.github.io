## 视频制作

### [开源项目 REA-Video 可把成片逆向拆解成镜头级复刻方案](https://x.com/i/status/2117837743833145749)

## 写代码

### [Claude Code 后台 subagent 状态更新成本降低约 99%](https://x.com/ClaudeDevs/status/2118063143167693011)

Claude Code 的后台 subagent 现在更省用量。以前它每 30 秒更新一次状态行，每次都要重读整段对话；现在由 Haiku 5.5 根据简短笔记生成，每次更新成本约降低 99%。 （来源：X List）

### [重新思考 Agent 时代的代码可读性标准](https://x.com/mattpocockuk/status/2117953152376799498)

Matt Pocock 认为人理解大量文本比 Agent 慢，过去可读性为的是让人高效看懂。现在可读性归结为两点：人需要时能介入并看懂代码，以及代码是否使用与人描述它时相同的领域语言。 （来源：X List）

### [Zach Lloyd 的 software factories 演讲被 Matt Pocock 推荐](https://x.com/mattpocockuk/status/2117930875287679098)

Matt Pocock 称 Zach Lloyd 关于 software factories 的演讲非常好，与他认为的当下最佳实践完全一致，并把对方加入必关注名单。 （来源：X List）

### [Matt Pocock 考虑把 skills 发布到 npm 供软件工厂使用](https://x.com/mattpocockuk/status/2117948553381515721)

Matt Pocock 在考虑把自己的 skills 发布到 npm 或其他 registry，以便在 software factories 中使用。这样可以按 Agent 动态调整，也可以固定到喜欢的版本。 （来源：X List）

### [录屏加口述，让 Agent 复刻自己常用的 App](https://x.com/thorstenball/status/2117935991008723235)

Thorsten Ball 想自建一个健身 App，不想截 50 张图再标注。他想起 Andreas Wissel 的做法：录下自己使用 App 的过程并口头说出想法，再交给 Agent。 （来源：X List）

### [huacnlee/cargo 缓解多 worktree AI 开发的 Rust 磁盘占用](https://x.com/huacnlee/status/2117892529949667444)

作者在电脑上用大量 worktree 做自动化 AI 开发，安装 huacnlee/cargo 后不再遇到 Rust 磁盘占用问题，也无需删除 target、避免全量重编译，每个项目大致控制在 20G 左右。 （来源：X List）

### [GitHub Copilot 进入 Xcode 内置编程助手](https://github.blog/changelog/2026-11-04-github-copilot-is-now-available-in-xcodes-coding-assistant)

现在可以在 Xcode 内置的编程助手中直接使用 GitHub Copilot，把 Copilot 带进原生 Xcode 工作流，该集成已进入公开预览。 （来源：GitHub Changelog · Copilot）

### [Gemini API CLI 配合编程 Agent 测试语音功能](https://x.com/_philschmid/status/2118039309534072849)

用 Gemini API CLI 生成语音，用 Chrome 的 fake audio capture 参数加载 WAV，再通过 Playwright 或 browser-use 点击麦克风按钮，最后在 DOM 中核对转写和界面状态，无需真实麦克风。 （来源：X List）

### [为什么要创建 skills 并逐步把成熟流程写成代码](https://x.com/dbreunig/status/2118014468571701271)

Peter Steinberger 提出个人额度限制是否还合理：随着能力提高，人们会希望支持一个代表项目的 Agent，让它运行循环并演进代码库，人类只负责筛选自动化。 （来源：X List）

### [监控基础设施的 Agent 工作流，可用 IaC 管理](https://x.com/0xblacklight/status/2118097867567231053)

Kyle Mistele 提出，用于监控基础设施和部署的 Agent 工作流正成为生产环境的一部分，为什么不用基础设施即代码，或 infrastructure-as-effects 来管理它们。 （来源：X List）

## 工作提效

### [逆向 Skill 的技巧：先让它完成任务再要求复刻](https://x.com/dotey/status/2118146071020888193)

想还原 Claude Design 的 Skill，直接问系统提示词会被拒。可先让它用该 Skill 完成一个最简单的设计，再要求做一个输入输出一样的 Skill，之后用追问完善。太复杂的 Skill 会被偷工减料。 （来源：X List）

### [开源 macOS 实时语音翻译与 AI 会议助手 Cicada](https://x.com/dotey/status/2118052017755005210)

Cicada 是开源的原生 macOS 工具，可在 Zoom、腾讯会议、飞书、YouTube 等应用中提供实时双语字幕和 AI 会议纪要，还能把你说的话翻译后通过虚拟麦克风传给会议软件。 （来源：X List）
