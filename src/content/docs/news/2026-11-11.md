## 写代码

### [Superlogical 团队的工作方式：直接推 main、机器辅助审查](https://x.com/mitchellh/status/2120221244478083249)

Mitchell Hashimoto 分享团队新做法：每个人被信任直接推送到 main，推送前由机器辅助代码审查，推送后再由人加机器继续审查，基本不用 PR。 （来源：X List）

### [Pi 的 Virtual Models：按任务复杂度自动路由模型](https://x.com/julien_c/status/2120168716251898041)

### [Gemini 4 Carbon 开发者指南：API 变化与多 Agent](https://x.com/_philschmid/status/2120209233019019723)

Google 的开发者指南涵盖 Gemini 4 Carbon 的 API 变化、最长 1M token 的长解码和多 Agent 模式。从 Argon 升级只需把 id 改成 gemini-4-carbon，/swarm 预览可创建多 Agent 团队。 （来源：X List）

### [DSPy 3.5 发布：更轻更快，去掉 LiteLLM](https://x.com/dbreunig/status/2120194751391736138)

DSPy 3.5 发布，底层更轻更快（去掉 LiteLLM），为 4.0 的新功能做准备；官方称体积缩小了 85%，开箱使用也更可靠。 （来源：X List）

## Agent

### [Home Repo：一个仓库统管多仓库协作的 Agent](https://x.com/mattpocockuk/status/2120260969750540327)

Matt Pocock 用一个“Home Repo”存放所有 skills、steering files 和 wiki，在其中运行 Agent，并在 AGENTS.md 里写明其他仓库的克隆位置，以此同时处理多个仓库。 （来源：X List）

### [Deep Agents 上下文工程：不堆满上下文也能记住](https://www.langchain.com/blog/context-engineering-deep-agents-remember)

LangChain 讲长时间运行的 Agent 会因上下文堆积而退化，介绍用卸载、摘要、skills、subagents 和 memory 让上下文窗口保持聚焦的方法。 （来源：LangChain Blog）

### [软件瓶颈变了：要让 Agent 好用，人只负责预览微调](https://x.com/dotey/status/2120237447963415014)

宝玉认为，Agent 最友好的软件接口是 cli、MCP 和代码，而非复杂 GUI；人只需检查结果并标记、评论、微调。以视频编辑器为例，一个播放器加标注工具就够了。 （来源：X List）

### [Resend 如何为 Agent 设计文档和工具](https://latent.space/p/resend/)

Latent Space 访谈 Resend 的 Zeno Rocha，讨论回答引擎优化（AEO）和 Agent 体验的边界，包括帮助 Claude Code 选中邮件 API 的文档，以及 Agent 发信所用的工具。 （来源：Latent Space）

### [Factory Workstreams：编排器管理 Agent 集群](https://x.com/dexhorthy/status/2120220674543476800)

Factory 的新功能 Workstreams 让一个编排器管理一群 Agent，并结合定时自动化与各类集成，用来完成大规模、长周期的任务。 （来源：X List）

### [Workday 用 LangGraph 搭企业级 Agent 平台](https://www.langchain.com/blog/how-workday-built-an-enterprise-scale-ai-agent-platform-with-langgraph-and-langsmith)

LangChain 案例：Workday 用 LangGraph 和 LangSmith 搭建内部 AI Agent 平台，把原型制作时间从数月缩短到不到一天，并满足合规需求。 （来源：LangChain Blog）

### [MKA 基准：测 Agent 处理复杂视觉文件的知识工作](https://x.com/_philschmid/status/2120281759598415961)

Google 与 Artificial Analysis 推出 MKA 基准，含 10 个行业 83 种职业的 200 个任务，每题约 70 条检查项，事实准确占 75%、视觉设计占 25%，所有模型在同一框架下运行。 （来源：X List）

### [双 Agent 协作：一个建模一个审查，做出可玩 3D 游戏](https://x.com/dotey/status/2120205106608210251)

Gemini Carbon 的演示中，一个 Agent 在 Blender 和 Three.js 上负责构建建模，另一个负责检查渲染结果，最终生成一款鹈鹕骑自行车逛 Google 园区的可玩 3D 游戏。 （来源：X List）
