- **[GPT-5.5 retirement in Codex：检查仍固定旧模型的任务](https://developers.openai.com/codex/changelog)**
  - 是什么：官方记录确认，GPT-5.5 于 10 月 14 日 19:00 UTC，即上海时间 10 月 15 日 03:00，从使用 ChatGPT 登录的 Codex 中退役。OpenAI API 与使用 API Key 认证的 Codex 会话不受此次变化影响。

- **[Claude Platform：OpenTelemetry export 进入 beta](https://platform.claude.com/docs/en/release-notes/overview)**
  - 是什么：10 月 14 日新增 OpenTelemetry export beta，可追踪 Messages API 请求与 Claude Managed Agents 会话。Python、TypeScript、C#、Go、Java、PHP 和 Ruby SDK 可发出 spans；API 端需在 Claude Console 配置 destination。同日还宣布 AWS 上可用 Managed Agents scheduled deployments。
  - 为什么值得看：现有日志、延迟和错误信息可以逐步连成请求链路，便于定位 agent 卡在哪一步、哪个工具或模型调用出了问题。接入时应保留 beta 状态这一前提。
  - 来源：Claude Platform 官方 release notes；与 Claude Blog 同事件合并。

- **[Claude Code v2.1.299–v2.1.300：空闲压缩与更细的观测](https://github.com/anthropics/claude-code/releases/tag/v2.1.300)**
  - 是什么：本窗口内两个版本合并记录。v2.1.299 公告终端空闲压缩：超过 200K tokens 的对话空闲约 54 分钟后，在一小时 prompt cache 到期前压缩；可通过 `idleCompaction` 设置关闭。v2.1.300 增加按缓存写入时长区分的 telemetry 字段，以及 OpenTelemetry GenAI trace 属性。
  - 为什么值得看：长会话隔一段时间继续做，可能面临缓存失效后的重复输入成本；压缩触发条件和可观测数据都值得纳入自己的工作流评估。
  - 来源：Anthropic 官方 Claude Code releases；与 X 上同功能讨论合并。

## 深读推荐
