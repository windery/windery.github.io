TL;DR：准备 Python 3.11 和 FFmpeg，用 `uv sync --frozen` 安装依赖后运行 `sh webui.sh`。首次启动会自动生成 `config.toml`；最少只要配一个 LLM 和一个素材源的 API Key，配音用免费的 Edge TTS 即可出第一条视频。用 CLI 时注意：素材来源不读取配置文件，需要用 `--video-source` 显式指定。

本文覆盖前置依赖、安装启动、关键配置、WebUI 和 CLI 的最小流程，以及 HTTP API 调用和常见问题。下列命令依据该 commit 的 README 与源码整理，未在本文写作过程中实际执行。

## 前置依赖

| 依赖 | 要求 | 说明 |
| --- | --- | --- |
| Python | 3.11 及以上，推荐 3.11 | `pyproject.toml` 声明 `>=3.11`，`.python-version` 和 Dockerfile 使用 3.11 |
| uv | 推荐 | README 默认用 `uv sync --frozen` 按 `uv.lock` 安装；`requirements.txt` 只为旧的 pip 方式保留 |
| FFmpeg | 必需 | 配音之后的阶段都需要 FFmpeg，见下文 |
| ImageMagick | 不需要 | 该快照的源码、Dockerfile 和 README 中都没有 ImageMagick；字幕由 `moviepy==2.2.1` 的 `TextClip` 渲染 |
| API Key | 至少两类 | 一个 LLM（默认 `moonshot`），一个在线素材源（CLI 默认 `pexels`）；Edge TTS 和本地素材不需要 Key |
| GPU | 可选 | 只有本地 Whisper 字幕、批量生成等较重的场景才明显受益 |

FFmpeg 的查找顺序，在源码中是：`config.toml` 的 `ffmpeg_path`（写入 `IMAGEIO_FFMPEG_EXE`）→ 系统 `PATH` 中的 `ffmpeg` → `imageio-ffmpeg` 自带的二进制。任务开始时会先执行一次 `ffmpeg -version`；探测失败时，除只生成文案或关键词的任务外，其他任务都会直接以 `preflight` 阶段失败。README 说“FFmpeg 通常会被自动下载”，但源码注释指出，项目锁定的 `imageio-ffmpeg` 不会在使用时补下载。所以最稳妥的做法是在系统里装好 FFmpeg，或者显式配置 `ffmpeg_path`。

依据：[pyproject.toml](https://github.com/harry0703/MoneyPrinterTurbo/blob/9887b459e754ee073c056d988499b91136af9662/pyproject.toml)、[app/utils/utils.py](https://github.com/harry0703/MoneyPrinterTurbo/blob/9887b459e754ee073c056d988499b91136af9662/app/utils/utils.py)、[app/config/config.py](https://github.com/harry0703/MoneyPrinterTurbo/blob/9887b459e754ee073c056d988499b91136af9662/app/config/config.py)、[app/services/task.py](https://github.com/harry0703/MoneyPrinterTurbo/blob/9887b459e754ee073c056d988499b91136af9662/app/services/task.py)、[README.md](https://github.com/harry0703/MoneyPrinterTurbo/blob/9887b459e754ee073c056d988499b91136af9662/README.md)。

## 安装与启动

### 本地部署

```bash
git clone https://github.com/harry0703/MoneyPrinterTurbo.git
cd MoneyPrinterTurbo
uv python install 3.11
uv sync --frozen
```

不用 uv 时，可以执行 `python3.11 -m venv .venv`，再 `pip install -r requirements.txt`。

在项目根目录启动：

```bash
# WebUI（macOS / Linux）；Windows 用 webui.bat
sh webui.sh

# HTTP API 服务
uv run python main.py
```

- `webui.sh` 依次尝试 `.venv` 中的 Python、`uv run streamlit`、PATH 中的 `streamlit`。它默认绑定 `127.0.0.1:8501`，端口被占用时在 8502–8599 中顺延，实际地址以终端输出为准。需要局域网访问时，设置 `MPT_WEBUI_HOST=0.0.0.0`。
- `main.py` 按 `listen_host` / `listen_port` 启动，默认是 `0.0.0.0:8080`。接口文档在 `http://127.0.0.1:8080/docs`。
- 首次启动时，如果没有 `config.toml`，程序会从 `config.example.toml` 复制一份。
- Windows 下，项目路径不要包含中文、特殊字符或空格（README 要求）。

### Docker

```bash
cp config.example.toml config.toml
docker compose -f docker-compose.release.yml up
```

`docker-compose.release.yml` 拉取 `ghcr.io/harry0703/moneyprinterturbo:latest`，同时启动 `webui`（8501）和 `api`（8080）两个容器，端口只映射到宿主机 `127.0.0.1`，并挂载 `./config.toml` 和 `./storage`。因此启动前必须先准备好 `config.toml`。

其他变体：

- `docker compose up`：用 `docker-compose.yml` 本地构建镜像，挂载整个项目目录。
- `docker-compose.gpu.yml`：基于 CUDA 镜像的 GPU 版。
- `docker-compose.claude.yml`：在镜像中安装 `claude` CLI，供 `claude_code` Provider 使用；容器内需要通过 `CLAUDE_CODE_OAUTH_TOKEN` 环境变量鉴权。

依据：[README.md](https://github.com/harry0703/MoneyPrinterTurbo/blob/9887b459e754ee073c056d988499b91136af9662/README.md)、[webui.sh](https://github.com/harry0703/MoneyPrinterTurbo/blob/9887b459e754ee073c056d988499b91136af9662/webui.sh)、[main.py](https://github.com/harry0703/MoneyPrinterTurbo/blob/9887b459e754ee073c056d988499b91136af9662/main.py)、[Dockerfile](https://github.com/harry0703/MoneyPrinterTurbo/blob/9887b459e754ee073c056d988499b91136af9662/Dockerfile)、[docker-compose.release.yml](https://github.com/harry0703/MoneyPrinterTurbo/blob/9887b459e754ee073c056d988499b91136af9662/docker-compose.release.yml)、[docker-compose.claude.yml](https://github.com/harry0703/MoneyPrinterTurbo/blob/9887b459e754ee073c056d988499b91136af9662/docker-compose.claude.yml)。

## 配置要点

所有配置都在 `config.toml`。WebUI 顶部的“基础设置”面板能修改其中大部分项，并写回该文件。密钥只应放在本地的 `config.toml` 里，不要提交到仓库。下表列出 `config.example.toml` 中最常用的字段：

| 字段（所在段） | 默认值 | 作用 |
| --- | --- | --- |
| `llm_provider`（`[app]`） | `"moonshot"` | 文案和关键词使用的 Provider；对应 `<provider>_api_key`、`<provider>_model_name`、`<provider>_base_url` 三个字段，后两个留空时使用注册表中的默认值 |
| `video_source`（`[app]`） | `"pexels"` | WebUI 的默认素材源；CLI 不读这一项 |
| `pexels_api_keys` / `pixabay_api_keys` / `coverr_api_keys` | `[]` | 库存素材 Key，写成列表；填多个时轮换使用 |
| `subtitle_provider`（`[app]`） | `"edge"` | `edge` 使用 TTS 时间轴，`whisper` 本地转写，留空不生成字幕 |
| `[whisper]` 段 `model_size` / `device` / `compute_type` | `large-v3` / `cpu` / `int8` | Whisper 模型参数；README 建议想更快时改用 `large-v3-turbo` |
| `ffmpeg_path`（`[app]`，默认注释掉） | 无 | 自动探测失败时，填写 FFmpeg 可执行文件的完整路径 |
| `material_directory`（`[app]`） | `""` | 素材缓存位置：空值表示 `storage/cache_videos`，`"task"` 表示放进各任务目录，也可以填绝对路径 |
| `material_concurrency` / `video_clip_concurrency` | 1 | 素材下载并发数、片段处理并发数，可选 1/2/4/6/8 |
| `video_codec` | `libx264` | 可改用 `h264_videotoolbox`、`h264_nvenc` 等硬件编码器；不可用时自动回退到 `libx264` |
| `api_key`（`[app]`） | `""` | 非空时，`/api/v1` 和 `/tasks` 都要求请求头 `x-api-key` |
| `enable_redis`、`max_concurrent_tasks`、`max_queued_tasks` | `false`、5、100 | API 的任务状态后端和并发上限 |
| `[proxy]` 段 `http` / `https` | 注释掉 | 库存素材搜索和下载使用的代理 |
| `[ui]` 段 | 由 WebUI 自动写入 | 保存 WebUI 的偏好；CLI 只读取其中的字幕和配音相关项 |

依据：[config.example.toml](https://github.com/harry0703/MoneyPrinterTurbo/blob/9887b459e754ee073c056d988499b91136af9662/config.example.toml)、[app/services/llm.py](https://github.com/harry0703/MoneyPrinterTurbo/blob/9887b459e754ee073c056d988499b91136af9662/app/services/llm.py)、[app/services/material.py](https://github.com/harry0703/MoneyPrinterTurbo/blob/9887b459e754ee073c056d988499b91136af9662/app/services/material.py)、[webui/Main.py](https://github.com/harry0703/MoneyPrinterTurbo/blob/9887b459e754ee073c056d988499b91136af9662/webui/Main.py)。

## 用 WebUI 出第一条视频

以下界面文字取自 `webui/i18n/zh.json`。

1. 展开“基础设置”，选择 LLM Provider 并填写 API Key；在素材源对应的位置填写 Pexels 或 Pixabay 的 Key。
2. 在“视频主题”中填一句话主题，点击“点击使用AI生成视频文案和关键词”。LLM 会填好“视频文案”和“视频关键词”，两者都可以手动修改。已有现成文案的话，直接粘贴进文案框即可。关键词要求是英文，因为生成关键词的 prompt 规定只输出英文检索词。
3. 在“视频设置”中选择视频比例（`9:16`、`16:9` 或 `1:1`）、视频来源、单个片段最大时长、同时生成视频数量。
4. 在“音频设置”中，TTS 服务器选“Azure TTS V1 (Edge TTS)”，再选一个和文案语言一致的音色，可以先试听。背景音乐保持“随机”即可。
5. 在“字幕设置”中按需调整字体、位置、颜色和描边。
6. 点击“生成视频”，等待进度条跑完。成片会出现在页面中，文件位于 `storage/tasks/<task_id>/final-1.mp4`。

耗时主要花在素材下载和剪辑编码上，取决于成片时长、机器性能和网络。默认的下载与片段处理都是串行的，可以通过上文的两个并发参数和 `video_codec` 调整。

依据：[webui/i18n/zh.json](https://github.com/harry0703/MoneyPrinterTurbo/blob/9887b459e754ee073c056d988499b91136af9662/webui/i18n/zh.json)、[webui/Main.py](https://github.com/harry0703/MoneyPrinterTurbo/blob/9887b459e754ee073c056d988499b91136af9662/webui/Main.py)、[app/services/llm.py](https://github.com/harry0703/MoneyPrinterTurbo/blob/9887b459e754ee073c056d988499b91136af9662/app/services/llm.py)。

## CLI 与 HTTP API

### CLI

最小命令：

```bash
uv run python cli.py --video-subject "人工智能如何改变日常生活" --video-source pixabay
```

最需要注意的是 `--video-source`。它的默认值固定为 `pexels`，CLI 不会读取 `config.toml` 中的 `video_source`（WebUI 会读）。如果只配置了 Pixabay 的 Key，却不传这个参数，素材阶段会因为 `pexels_api_keys` 未设置而失败。

| 参数 | 默认值 | 说明 |
| --- | --- | --- |
| `--video-subject` / `--video-script` | 无 | 两者至少给一个；给了 `--video-script` 就跳过 LLM 写稿 |
| `--video-terms` | 自动生成 | 逗号分隔的素材检索词 |
| `--video-source` | `pexels` | 可选 `pexels`、`pixabay`、`coverr`、`wavespeed`、`volcengine_seedance`、`ofox`、`metaso_minimax`、`muapi`、`openai_image`、`local` |
| `--video-materials` | 无 | 配合 `local` 使用，逗号分隔的本地文件路径 |
| `--stop-at` | `video` | 执行到指定阶段就停止：`script`、`terms`、`audio`、`subtitle`、`materials`、`video` |
| `--video-aspect` | `9:16` | 也可以是 `16:9`、`1:1` |
| `--video-count` | 1 | 生成几条成片 |
| `--video-clip-duration` | 5 | 每个片段的最大时长（秒） |
| `--voice-name` | `[ui].voice_name`，否则 `zh-CN-XiaoxiaoNeural-Female` | 传 `no-voice` 生成无配音视频；其他 Provider 的音色用 `gemini:`、`kokoro:` 等前缀 |
| `--custom-audio-file` | 无 | 使用自备音频，跳过 TTS；这种情况下只有 `subtitle_provider = "whisper"` 才能生成字幕 |
| `--bgm-type` | `random` | 也可以是 `none`、`custom`、`sonilo`、`elevenlabs` |
| `--batch-file` | 无 | JSON 数组或 JSONL 清单，最多 100 个任务、不超过 1 MiB |
| `--confirm-<source>-charge` | 关 | 使用付费 AI 视频源生成素材或成片时必须加 |

参数取值的优先级：命令行显式参数 > `config.toml` 中 `[ui]` 保存的值（只限字幕、配音、片段速度、适配方式等字段）> 内置默认值。背景音乐、视频数量、段落数等不会沿用 WebUI 的保存值。如果 `[ui].voice_mode` 保存的是“无配音”或“上传音频”，CLI 会按无配音处理，需要配音时要显式传 `--voice-name`。

运行结果：成功时向 stdout 输出一个 JSON 对象并返回 0；任务失败返回 1；参数或清单错误返回 2；日志写到 stderr。只想快速看文案效果，可以用 `--stop-at script`。

### HTTP API

API 是异步的：创建任务后返回 `task_id`，再轮询任务状态。

```bash
curl -X POST http://127.0.0.1:8080/api/v1/videos \
  -H "Content-Type: application/json" \
  -d '{"video_subject": "为什么要多喝水", "video_source": "pixabay", "voice_name": "zh-CN-XiaoxiaoNeural-Female"}'

curl http://127.0.0.1:8080/api/v1/tasks/<task_id>
```

- 其他接口：`/api/v1/subtitle`、`/api/v1/audio` 只生成字幕或配音；`/api/v1/scripts`、`/api/v1/terms` 只调用 LLM；`/api/v1/musics`、`/api/v1/video_materials` 列出或上传 BGM 和本地素材。
- 任务状态值：`4` 表示处理中，`1` 表示完成，`-1` 表示失败；失败时附带 `failed_stage` 和 `error`。
- API 对单次任务的成片数量限制为 1–5 条，片段时长限制为 1–15 秒，CLI 没有这两项上限。
- 配置了 `api_key` 后，所有请求都要带 `x-api-key` 头，下载 `/tasks/...` 下的成片也一样。浏览器地址栏无法附带自定义请求头，需要用 HTTP 客户端下载。
- 浏览器跨域访问默认关闭，需要时通过环境变量 `CORS_ALLOWED_ORIGINS` 设置白名单。curl 等服务端调用不受 CORS 限制。

依据：[cli.py](https://github.com/harry0703/MoneyPrinterTurbo/blob/9887b459e754ee073c056d988499b91136af9662/cli.py)、[app/services/material.py](https://github.com/harry0703/MoneyPrinterTurbo/blob/9887b459e754ee073c056d988499b91136af9662/app/services/material.py)、[README.md](https://github.com/harry0703/MoneyPrinterTurbo/blob/9887b459e754ee073c056d988499b91136af9662/README.md)、[app/controllers/v1/video.py](https://github.com/harry0703/MoneyPrinterTurbo/blob/9887b459e754ee073c056d988499b91136af9662/app/controllers/v1/video.py)、[app/controllers/v1/llm.py](https://github.com/harry0703/MoneyPrinterTurbo/blob/9887b459e754ee073c056d988499b91136af9662/app/controllers/v1/llm.py)、[app/models/schema.py](https://github.com/harry0703/MoneyPrinterTurbo/blob/9887b459e754ee073c056d988499b91136af9662/app/models/schema.py)、[app/asgi.py](https://github.com/harry0703/MoneyPrinterTurbo/blob/9887b459e754ee073c056d988499b91136af9662/app/asgi.py)、[app/models/const.py](https://github.com/harry0703/MoneyPrinterTurbo/blob/9887b459e754ee073c056d988499b91136af9662/app/models/const.py)。

## 常见问题

| 现象 | 原因与处理 |
| --- | --- |
| 任务在 `preflight` 阶段报 `ffmpeg is not available` | 没有找到可用的 FFmpeg。在系统中安装 FFmpeg，或设置 `ffmpeg_path` |
| 素材阶段报 `pexels_api_keys is not set` | 素材源与已配置的 Key 不一致。WebUI 中检查“视频来源”，CLI 加上 `--video-source` |
| 关键词生成了，但素材不贴题 | 手动修改英文关键词；或开启 `match_materials_to_script`，让关键词和素材按文案顺序排列 |
| `OSError: [Errno 24] Too many open files` | 系统文件句柄上限太低，先执行 `ulimit -n 10240` 再启动 |
| Whisper 模型下载失败 | 从 Hugging Face 手动下载，放到 `models/whisper-<model_size>` 目录；`webui.sh` 中有一行注释掉的 `HF_ENDPOINT` 镜像设置可以启用 |
| 使用自备音频后没有字幕 | 自备音频没有 TTS 时间轴，只有 `subtitle_provider = "whisper"` 时才能生成字幕 |
| Edge 字幕偶尔缺失 | 时间轴与文案匹配失败时，源码会输出无字幕的视频，不会自动改用 Whisper（避免意外下载数 GB 的模型） |
| 合成长时间停在 50% 左右 | FFmpeg 拼接卡住时，`ffmpeg_concat_timeout_seconds`（默认 3600 秒）超时后任务会失败；机器较慢时可调大 |
| WebUI 打开是空白页 | README 建议换 Chrome 或 Edge |
| 在不受信任的网络中暴露 API | 设置 `api_key`；`listen_host` 改为 `127.0.0.1`；Redis 只允许本应用访问 |
